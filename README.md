# Athletic Minds Tutoring Website

Marketing website for Athletic Minds Tutoring — academic support for student-athletes, including flexible scheduling, travel tutoring, exam proctoring coordination, group study programs, and college prep.

## Live Site
- https://athleticmindstutoring.com

## Tech Stack
- Static site: HTML / CSS / JavaScript
- Hosting: GitHub Pages
- DNS / CDN: Cloudflare

## Repository Structure
- `/index.html` — main entry point
- `/assets/` — images, icons, fonts (if applicable)
- `/css/` — site styles
- `/js/` — site scripts (navigation, contact form, etc.)
- `/robots.txt` — search engine crawling rules
- `/sitemap.xml` — sitemap for indexing
